AURA HEALTH: DIGITAL TWIN AI - CORE TECHNICAL SPECIFICATION & SYSTEM DESIGN
================================================================================

1. PROJECT OVERVIEW
-------------------
Aura Health is a high-fidelity "Digital Twin" simulator that bridges the gap 
between raw medical data (PDF reports) and actionable health intelligence. It 
visualizes a user's internal health state onto a 3D anatomical model and uses 
clinical-grade reasoning to project future health trends.

2. CORE TECH STACK
------------------
* FRONTEND: 
  - React (Vite) + TypeScript
  - Three.js / React Three Fiber (3D Anatomical Body & Holographic Shaders)
  - Framer Motion (Fluid UI Transitions & High-Fidelity Animations)
  - Zustand (High-speed Global State Management for real-time risk syncing)

* BACKEND: 
  - FastAPI (Python) - High-performance asynchronous API framework
  - Pydantic (Strict schema validation for clinical data integrity)
  - MongoDB (Persistent storage for user "Digital Twin" profiles and report history)

* AI & REASONING ENGINE:
  - Cerebras Inference (Llama-3-70B / Claude-3.7) - Supercomputer-speed inference
  - Custom Biological Simulation Logic (Deterministic clinical formulas)
  - RAG (Retrieval-Augmented Generation) for longitudinal trend analysis

3. SYSTEM ARCHITECTURE & LOGIC
------------------------------

A. THE "BIO-REASONING" PIPELINE
   Raw PDF Report -> NLP Entity Extraction (Cerebras) -> Clinical Schema 
   -> Simulation Engine -> Multi-Agent Narrative -> Interactive 3D Dashboard.

B. CLINICAL FORMULAS (DETERMINISTIC LAYER)
   Unlike standard AI, Aura uses verified medical formulas for organ scores:
   - Heart Risk = (Age*0.3) + (BMI*1.5) + (Smoking*20) - (Sleep*2.0)
   - Lung Risk = Heavily weighted towards smoking history (45% instant surge)
   - Every organ uses a unique weighted impact matrix for various life factors.

C. WHO & MEDICAL GUARDRAILS
   The system aligns with WHO framework for "Integrated People-Centred Health 
   Services" (IPCHS).
   - Stabilization Protocol: AI is barred from "prescribing" (Hard Prompting).
   - Diagnostic Thresholds: Uses specific marker alerts (e.g., HbA1c > 6.5%).

4. KEY DIFFERENTIATORS (THE "WOW" FACTORS)
------------------------------------------
1.  ASYNCHRONOUS EVENT LOOP: Data flows from PDF extraction to 3D pulse response 
    in under 2 seconds.
2.  MEDICAL INTERPRETABILITY: Every score provides a "Causal Narrative" 
    explaining WHY a score is high (e.g., "Alcohol intake is compounding with 
    low activity to stress the metabolic pathway").
3.  TEMPORAL "WHAT-IF" SIMULATION: Users can toggle habits (e.g., "What if I 
    stop smoking?") and watch the 3D model change colors in real-time.
4.  MULTI-LANGUAGE ACCESSIBILITY: Full semantic support for English, Hindi, 
    and Telugu, bringing high-end health intelligence to billions.
